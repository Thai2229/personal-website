# References

- https://www.ouckah.com/about: main inspiration. Next.js site. Header nav (about, work, press, media kit, resources), breadcrumb (Home / About), short bio in lowercase, "what i do" section, official profile links, selected coverage, "Let's Connect" footer. Ours should be similar in structure but more stylized.
- https://github.com/codemure-official/ink-bleed-theme-changer: reference for the light/dark toggle. Click-originating ink-spread transition (WebGL2 with CSS fallback, GSAP, html2canvas), theme saved in local storage, `T` key toggles. MIT licensed, but described as a concept demo, so we'd adapt the idea rather than depend on it.
