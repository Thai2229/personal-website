# References

- https://www.ouckah.com/about: main inspiration. Next.js site. Header nav (about, work, press, media kit, resources), breadcrumb (Home / About), short bio in lowercase, "what i do" section, official profile links, selected coverage, "Let's Connect" footer. Ours should be similar in structure but more stylized.
- https://github.com/codemure-official/ink-bleed-theme-changer: reference for the light/dark toggle. Click-originating ink-spread transition (WebGL2 with CSS fallback, GSAP, html2canvas), theme saved in local storage, `T` key toggles. MIT licensed, but described as a concept demo, so we'd adapt the idea rather than depend on it.
- https://sawad.framer.website/: closest outline of the overall layout we want (a Framer portfolio template). Nav: Home, Projects, Experience, Tools, Thoughts. One long page: hero with name and tagline, big "SOFTWARE ENGINEER" title, stat counters (years, projects, clients), recent projects, experience timeline, tools list, thoughts/blog list. Fonts: Inter, Poppins, Satoshi. Palette: near-black `#151312`, warm off-white `#faf7f3`, lime accent `#c5ff41`, orange `#f46c38`, greys `#6a6b6e` / `#998f8f`. Must-have element: the card on the left with a face looking up.
  - Left card detail: static (no motion). Rounded white card with a portrait in a rounded square on a bold orange background, subject looking up and to the side. Large bold name below, grey two-line tagline, row of four orange outline social icons. Decorative dashed orange arcs cross the card, with a small orange circle badge (flame icon) sitting on one arc.
